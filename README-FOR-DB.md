# Исторический документ: ранняя модель БД

Этот файл сохранён только для совместимости со старыми ссылками. Исходный текст описывал проектируемую схему, включая функции, которые не входят в текущий WB Web v1 (например AI-рекомендации), поэтому он **не является актуальной спецификацией БД**.

Канонические источники:

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — текущая архитектура и классы данных;
- [`docs/DATA_AND_METRICS.md`](docs/DATA_AND_METRICS.md) — semantic/data model на уровне продукта;
- `backend/models/` — фактические SQLAlchemy models;
- `backend/alembic/` — единственная каноническая история схемы PostgreSQL.

Схема production DB создаётся и изменяется только Alembic migrations. Не используйте старые SQL/ERD-примеры из истории проекта как инструкцию установки.
