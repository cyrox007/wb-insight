# WB Insight — жизненный цикл аккаунта

## Уже реализовано

- регистрация;
- вход, refresh и logout;
- demo subscription;
- профиль продавца;
- подключение и удаление WB-кабинетов;
- тариф/billing baseline;
- административное управление пользователями.

## Что нужно закрыть до RC

1. Password reset/recovery через подтверждённый канал.
2. Понятный сценарий отмены подписки.
3. Процедура обработки ошибочного платежа/возврата согласно утверждённой policy.
4. Деактивация или удаление аккаунта с определённым retention данных.
5. Безопасный support flow для потерянного доступа/блокировки.
6. Audit trail административных действий, влияющих на доступ или оплату.

Если часть сценариев остаётся ручной в `1.0.0`, она должна выполняться через безопасную административную процедуру и не требовать прямого редактирования production DB.

Статус этих задач является release gate и отражается в `RELEASE_ROADMAP.md`.
