# WB Insight — onboarding продавца

## Цель

Новый пользователь должен получить первые полезные показатели без предварительного изучения интерфейса и устройства WB API.

Основной путь состоит из трёх шагов:

1. подключить кабинет Wildberries;
2. дождаться появления первых синхронизированных источников;
3. добавить себестоимость для точного расчёта прибыли.

Себестоимость не блокирует просмотр продаж, выплат и другой аналитики, которая уже доступна из Wildberries.

## Мастер первого запуска

На маршруте `/dashboard` показывается компактный мастер первого запуска.

Он:

- проверяет наличие активного WB-подключения;
- показывает прогресс первичной синхронизации по источникам;
- ведёт напрямую на вкладку подключения кабинета;
- ведёт напрямую на вкладку себестоимости;
- позволяет скрыть подсказки после появления первых полезных данных.

Состояние скрытия хранится отдельно для каждого пользователя в браузере.

## Подключение Wildberries

Экран подключения объясняет только необходимые действия:

1. открыть «Профиль организации → Интеграции по API»;
2. создать базовый токен для ручной интеграции;
3. включить категории «Контент», «Аналитика», «Цены и скидки», «Статистика», «Продвижение», «Финансы»;
4. выбрать уровень «Только чтение»;
5. вставить токен в WB Insight.

После отправки WB Insight автоматически проверяет тип токена, срок действия, категории доступа, режим «Только чтение» и доступность токена через WB API.

Ошибки проверки сопровождаются конкретным действием для пользователя. Проблемы сервисных реквизитов WB Insight отдельно обозначаются как серверная проблема, чтобы пользователь не пытался перевыпускать корректный токен.

## Первичная синхронизация

После подключения backend создаёт состояния и задачи по всем источникам аналитики.

Главный экран автоматически обновляет прогресс первичной синхронизации примерно раз в шесть секунд. Как только появляется первый пригодный набор данных, дашборд повторно загружает показатели и перестаёт заставлять пользователя ждать полной загрузки всех источников.

Источники отображаются отдельными статусами: товары, заказы, продажи, остатки, цены, финансы, реклама, воронка и платное хранение.

## Себестоимость

Себестоимость — рекомендуемый, но неблокирующий шаг.

Без неё пользователь уже может смотреть доступные факты Wildberries. Интерфейс прямо сообщает, что прибыль и юнит-экономика станут точнее после заполнения себестоимости.

Переход из onboarding открывает сразу вкладку `/dashboard/profile?tab=costs`.

## Глубокие ссылки настроек

Профиль поддерживает параметр `tab`:

- `/dashboard/profile?tab=connections` — кабинеты Wildberries;
- `/dashboard/profile?tab=costs` — себестоимость;
- `/dashboard/profile?tab=expenses` — прочие расходы;
- `/dashboard/profile?tab=profile` — профиль и налог.

Это позволяет подсказкам вести пользователя прямо к нужному действию.

## Что остаётся отдельным этапом

Подключение через OAuth без ручного копирования токена зависит от партнёрского оформления WB Insight и публикации соответствующего сценария Wildberries. До этого ручной Base-token flow остаётся основным production-путём.
