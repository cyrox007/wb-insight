# 🚀 **Проект: WB Insight — Интеллектуальная панель управления продажами на Wildberries**

## 🔍 **Суть проекта**

**WB Insight** — это enterprise-класс SaaS-платформа, которая **заменяет Google Таблицы и Telegram-ботов** как основной инструмент аналитики для продавцов Wildberries.  
В отличие от существующих решений, она не просто **отображает данные**, а **принимает решения за пользователя**, превращая сырые метрики в **готовые действия для роста прибыли**.
