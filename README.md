# 🚀 **Проект: WB Insight — Интеллектуальная панель управления продажами на Wildberries**

## 🔍 **Суть проекта**

**WB Insight** — это enterprise-класс SaaS-платформа, которая **заменяет Google Таблицы и Telegram-ботов** как основной инструмент аналитики для продавцов Wildberries.  
В отличие от существующих решений, она не просто **отображает данные**, а **принимает решения за пользователя**, превращая сырые метрики в **готовые действия для роста прибыли**.

---
## 📊 **Что делает система?**

На основе **официального WB API** и **данных, введённых пользователем**, платформа автоматически рассчитывает:

### ✅ **Финансовую картину (Unit-экономика)**
- **Реальную прибыль** — с учётом **себестоимости**, **комиссии WB**, **логистики**, **хранения**, **штрафов**, **налога** и **рекламных расходов**.
- **Маржинальность и рентабельность** по каждому артикулу.
- **ДРР (ROI рекламы)** — эффективность каждой рубля, вложенного в продвижение.

> 💡 **Ключевое отличие**: Wildberries показывает **выручку**, а WB Insight — **чистую прибыль**.

### ✅ **Операционную аналитику**
- **Остатки по складам** и **оборот товаров**.
- **Прогноз дефицита**:  
  > *«Остатков хватает на 3 дня. Если не поставить 50 шт. до 10 ноября — вы потеряете 217 000 ₽»*.
- **Анализ по регионам и размерам** (для одежды/обуви).
- **План vs Факт** с прогнозом выполнения.

### ✅ **Стратегическое управление ассортиментом**
- **ABC-анализ по прибыли** (а не по выручке!):
  - **Категория A**: 20% товаров → 80% прибыли
  - **Категория C**: 50% товаров → 5% прибыли → кандидаты на вывод
- Рекомендации: **«Увеличьте закупку A-товаров»**, **«Оптимизируйте или уберите C-товары»**.

### ✅ **ИИ-аналитик (виртуальный CFO)**
- **Диалоговый интерфейс**:  
  > *«Почему упал ROAS по артикулу 1234567 на прошлой неделе?»*  
  → Система анализирует рекламу, цены, CTR, остатки и даёт **человеческий ответ**.
- **Прогноз сезонного спроса**:  
  > *«Начните закупать утеплённые носки в августе — пик продаж в ноябре»*.
- **Рекомендации по карточке**:  
  > *«CTR ниже среднего. Обновите главное фото — это даст +22% к конверсии»*.

## ⚙️ **Техническая архитектура**

- **Бэкенд**: **FastAPI** (REST API) — высокая производительность, асинхронность, встроенная валидация.
- **Фронтенд**: **Vue.js** — адаптивный веб-интерфейс с дашбордами, графиками, таблицами.
- **Мобильные приложения**: **нативные** (Kotlin для Android, Swift для iOS) — с push-уведомлениями и offline-режимом.
- **База данных**: **PostgreSQL** — хранение пользователей, подписок, себестоимости, кэша данных WB.
- **Интеграция с WB**: только через **официальный API** (категории Analytics, Statistics, Promotion) + **базовый токен** (только на чтение).
- **Безопасность**: токены WB хранятся в **зашифрованном виде** (AES-256), передача — только по HTTPS.

> 🛡 **Юридическая чистота**: использование **базового токена** полностью соответствует правилам Wildberries. Подача заявки в **Каталог решений** — в планах.
